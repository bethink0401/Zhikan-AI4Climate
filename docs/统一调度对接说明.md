# 统一调度对接说明（Traffic Agent / Coordinator）

面向：全组联调  
工程根目录：`空气污染预警溯源多智能体系统/`

---

## 1. 一句话怎么接

每个 Agent 实现同一签名，由 Coordinator 按固定顺序调用：

```text
task JSON
  → AirQualityAgent.run(task)
  → MeteorologyAgent.run(task)
  → TrafficAgent.run(task)                 ← 已就绪
  → SpatialAgent.run(task, meteo_result)
  → SourceAgent.run(air, meteo, traffic, spatial)
  → DecisionAgent.run(source, traffic, spatial, meteo)
  → ReportAgent.run(全部结果)
  → 汇总 JSON 返回前端
```

最小可运行入口（当前）：

```bash
cd 空气污染预警溯源多智能体系统
python agents/coordinator_min.py
```

把各成员真实 Agent 替换 `coordinator_min.py` 里的 `_placeholder(...)` 即可完成统一调度。

## 3. 统一输入（全组唯一任务格式）

```json
{
  "task_id": "HK_MK_2023_0800",
  "station_name": "Mong Kok Roadside",
  "station_id": "mk_roadside",
  "start_time": "2023-08-15 08:00:00",
  "end_time": "2023-08-15 11:00:00",
  "lat": 22.3193,
  "lon": 114.1694
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `task_id` | string | 建议 | 任务追踪 ID |
| `station_name` | string | 是 | 推荐：`Mong Kok Roadside` / `Causeway Bay Roadside` / `Central Roadside` |
| `station_id` | string | 否 | 各组内部站号；Traffic 主要靠 `station_name` |
| `start_time` | string | 是 | `YYYY-MM-DD HH:MM:SS` |
| `end_time` | string | 是 | 同上；左闭右开按小时切时段 |
| `lat` / `lon` | float | 建议 | Spatial / Meteo 使用；Traffic 可忽略 |

别名已支持：`旺角` / `铜锣湾` / `中环` / `Mong Kok` 等（见 `data/station_mapping.json`）。

## 4. 统一输出（每个 Agent 必须遵守）

```json
{
  "agent_name": "TrafficAgent",
  "status": "success",
  "result": {},
  "evidence": ["..."],
  "confidence": 0.78,
  "data_quality": {
    "missing_rate": 0.0,
    "note": "..."
  },
  "created_at": "2026-07-21 23:10:22"
}
```

| 字段 | 约定 |
|------|------|
| `agent_name` | 固定英文名，见下表 |
| `status` | `success` / `warning` / `error`；**缺数据用 warning，不要抛异常打断总控** |
| `result` | 业务字段对象 |
| `evidence` | 字符串数组，供溯源/报告引用 |
| `confidence` | 0–1 |
| `data_quality.missing_rate` | 0–1 |
| `data_quality.note` | 人类可读说明 |
| `created_at` | `YYYY-MM-DD HH:MM:SS` |

### agent_name 固定值

| agent_name |
|------------|
| `AirQualityAgent` |
| `MeteorologyAgent` |
| `TrafficAgent` |
| `SpatialAgent` |
| `SourceAgent` |
| `DecisionAgent` |
| `ReportAgent` |

## 5. 推荐 Python 接口（方便 Coordinator 调用）

```python
class XxxAgent:
    name = "XxxAgent"

    def run(self, task: dict, **deps) -> dict:
        """返回统一输出 JSON（dict）。"""
        ...
```

依赖注入建议（与分工表一致）：

```python
air_result = AirQualityAgent().run(task)
meteo_result = MeteorologyAgent().run(task)
traffic_result = TrafficAgent().run(task)
spatial_result = SpatialAgent().run(task, meteo_result=meteo_result)
source_result = SourceAgent().run(
    task,
    air_result=air_result,
    meteo_result=meteo_result,
    traffic_result=traffic_result,
    spatial_result=spatial_result,
)
decision_result = DecisionAgent().run(
    task,
    source_result=source_result,
    traffic_result=traffic_result,
    spatial_result=spatial_result,
    meteo_result=meteo_result,
)
report_result = ReportAgent().run(
    task,
    air_result=air_result,
    meteo_result=meteo_result,
    traffic_result=traffic_result,
    spatial_result=spatial_result,
    source_result=source_result,
    decision_result=decision_result,
)
```

## 6. Traffic Agent：下游可直接用的字段

调用：

```python
from agents.traffic_agent import TrafficAgent
traffic_result = TrafficAgent().run(task)
```

### 6.1 Source Agent 必用字段

| 路径 | 含义 | 建议用法 |
|------|------|----------|
| `result.traffic_pressure_score` | 0–1 交通污染压力 | 溯源公式权重 **0.25** |
| `result.traffic_pressure` | `low/medium/high` | 风险档位辅助 |
| `result.heavy_vehicle_signal` | 货车+巴士信号 | 增强交通源判断 |
| `evidence` | 证据句 | 写入证据链 |

分工表交通源公式：

```text
traffic_source ≈
  0.35 × NO2异常分数
+ 0.25 × 交通污染压力指数(score)
+ 0.20 × 上风向道路匹配分数
+ 0.10 × 低风速分数
+ 0.10 × 路边站增强分数
```

参考实现：`agents/source_agent_stub.py`（可直接替换为真实 Source）。

### 6.2 Decision Agent 必用字段

| 路径 | 含义 |
|------|------|
| `result.vehicle_focus` | 重点车型，如 `["Bus","Goods Vehicle","Taxi"]` |
| `result.bus_ratio` / `goods_vehicle_ratio` / `taxi_ratio` | 0–1 |
| `result.dominant_vehicle_types` | 占比最高车型 |
| `result.road_links` | ATC 道路名，可作建议道路候选 |

### 6.3 Report / 前端卡片

| 路径 | 展示建议 |
|------|----------|
| `traffic_pressure` + `traffic_pressure_score` | 压力等级卡片 |
| `proportions_pct` | 车型比例图 |
| `vehicle_focus` | 重点车型标签 |
| `evidence` | 交通段文字说明 |
| `meta.peak_time_slot` | 窗口内压力峰值小时 |

### 6.4 成功样例（Mong Kok 早高峰摘要）

```json
{
  "agent_name": "TrafficAgent",
  "status": "success",
  "result": {
    "traffic_pressure": "high",
    "traffic_pressure_score": 0.7363,
    "dominant_vehicle_types": ["Franchised Bus DD", "Private Car", "Taxi"],
    "heavy_vehicle_signal": "high",
    "bus_ratio": 0.426,
    "goods_vehicle_ratio": 0.17,
    "vehicle_focus": ["Bus", "Goods Vehicle", "Taxi"],
    "road_links": ["NATHAN RD (from SHANTUNG ST to DUNDAS ST)"]
  },
  "confidence": 0.82
}
```

完整样例：`examples/day9_coordinator_output.json`、`examples/traffic_agent_case_outputs.json`。

## 8. Coordinator 如何替换占位（对接步骤）

打开 `agents/coordinator_min.py`，替换占位：

```python
# 合入后
from agents.air_quality_agent import AirQualityAgent
air_result = AirQualityAgent().run(task)
```

同理替换：

| 占位位置 | 替换为 |
|----------|--------|
| AirQuality 占位 | `AirQualityAgent().run(task)` |
| Meteorology 占位 | `MeteorologyAgent().run(task)` |
| Spatial 占位 | `SpatialAgent().run(task, meteo_result=...)` |
| Source stub | `SourceAgent().run(...)`（可先对照 stub） |
| Decision 占位 | `DecisionAgent().run(...)` |
| Report 占位 | `ReportAgent().run(...)` |

**Traffic 一行已是真实实现，无需改：**

```python
traffic_result = self.traffic.run(task)
```

联调验收标准：

1. `python agents/coordinator_min.py` 退出码 0  
2. `pipeline_status.traffic_ready == true`  
3. `source` 能读到 `traffic_pressure_score`  
4. 汇总 JSON 含 7 个 agent 键

## 10. 异常与边界（全组统一）

| 情况 | 要求 |
|------|------|
| 数据缺失 / API 失败 | 返回 `status=warning` + `data_quality.note`，**不要 raise 中断链路** |
| 时间格式 | 统一到小时；Traffic 映射为 `0800-0900` |
| JSON 字段名 | 不要擅自改 `agent_name` / 顶层结构 |
| 限行措辞 | 用「建议」，不做自动执法表述 |
| 压力指数 | 仅风险判断，不等于精确排放贡献率 |
