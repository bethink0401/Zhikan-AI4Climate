## 实验二：创新二留出站点观测回测 ⚠️ 阴性结果（如实报告）

**实验假设**：双尺度动态传播的风险区域能在留出监测站的实测数据上显示判别价值。

**数据划分**：源站 Mong Kok（2024），留出验证站 Central（3.9 km）与 Causeway Bay（4.6 km）；全年 3 小时窗口共 **4072 对**（预测， 观测）；留出站自身观测仅作验证标签、从不输入任何方法；历史气象驱动回测（Open-Meteo Archive 再分析），非预报。

**指标**：站点点位"是否被预警区域覆盖" vs "实测 NO2 超自身 p90"的 Precision/Recall 与 ROC-AUC（连续场值/软评分）。

**结果（阴性，全部保留）**：三方法在 3.9–4.6 km 留出站上**均无判别力**——A/B 召回 0（风险半径 1–2 km 级，覆盖不到留出站）、C AUC 0.458（低于随机）；2024 年 calm 窗口仅 2 个（静风分条件样本不足）。

**结论与边界**：EPD 路边站网间距（≥3.9 km）超过全部方法的冻结风险半径，**点位级观测验证在当前站网几何下不可行**——这本身是对适用范围的量化发现：本系统的空间传播验证目前只能依靠数值参考（欧拉与拉格朗日两种结构下优势均显著，见 V8），**不得宣称真实观测空间精度**；观测级验证需要更密的监测网或移动观测，列为数据条件成熟后的工作。导出：`v9_propagation_manifest.json`、`v9_propagation_metrics.json`、`v9_propagation_by_weather.csv`。

**PPT 一句话**：动态传播的空间优势已在两种独立结构的数值参考下验证；在真实站网几何下，点位级观测验证因站间距大于风险半径而不可行——这一适用边界被如实量化并写入结论。

   ——即"不显著"，但**方向不利**。这是对创新一"分类一致性更强"这一主张的**阴性证据**，
   与 V9.5 以来"合成域领先、真实域不领先"的结论一致。
2. **风险控制复现，但只按其实际范围表述**：C 在预设的 **36 个弱证据负例窗口**中
   **未发生交通误报**（全场最低；B 为 9、B+ 为 3、A 为 4），延续了 2024 开发数据的
   表现。**这只说明"在这 36 个预设弱证据窗口内零误报"**，不能外推为"所有真实事件的
   误报率是 0"，也不能仅凭这一项断定系统总体更可靠。
3. **相对单源基线仍然大幅领先**：C 相对 A 的优势明确（0.438 vs 0.321）。
4. **两套独立标注口径下 B/B+ 均不低于 C**（v2 甚至 B+ 最高）——不再是"某一套标注的偶然"。
5. 当年标注分布与 2024 差异明显（积聚窗仅 3 个、不确定窗 104 个），因为标注判据是
   **年内分位**的，逐年重标定必然改变类别比例；这本身说明"跨年份泛化"比"同一年内的
   留出"更难，也说明本盲测确实换了一套分布。
6. **样本量限制，逐类结果不可过度解读**：积聚类**只有 3 个真值窗**，C 的积聚召回
   0.667 实际是 **3 判对 2**——不足以支撑任何关于该类别泛化能力的结论（B/B+ 该类
   召回均为 0，同样只是 3 个样本上的表现）。PPT 中不得单独引用该类数字。
7. **弃判与错判数必须同时披露，防"靠弃判降误报"的质疑**：C 弃判率 0.308、B 0.274
   ——差距不大，且 C 的弃判并未明显更低；同时**错判窗口数 B 70 个、C 112 个**
   （相差 42 个）。两者合并的结论是：**降低某一类高风险误报，不等于整体分类表现更好**
   ——Macro-F1 的 CI 跨 0 而错判数差 42，正说明 C 的优势集中在特定风险类型上，
   而非全面占优。

**口径一致性（必须与开发年完全相同，否则不可比）**：本次盲测沿用与 2024 开发年
**完全相同的"全年基线"口径**（`load_station_no2_p90` 的 `as_of=None`），因此它同样带有
V9.1 已披露的**回顾性框架**说明——评价的是**代理标签的跨年份泛化**，不是部署态的前向
预测（PIT 口径的结果另见 V9.5/V9.7 两处）。把盲测做成 PIT 会同时改变口径与年份两个
变量，反而不可比，因此本轮刻意不改。

**不撤回、不调参**：按审查要求第 6 条，无论结果是否领先，本轮**封存结果、不再用同批
数据调参**；`protocol.json` 的 `v9_9_blind_run` 已把该年记为 `EXECUTED_ONCE /
regression_only`（`v9_8_preregistration.blind_year.not_yet_run` 同步改为 `false`）。
创新一的最终主张相应收窄为：**多源证据链 + 弱证据风险控制**，不宣称真实溯源准确率领先。
