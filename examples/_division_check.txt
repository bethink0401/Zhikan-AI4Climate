P0: 香港空气污染预警溯源多智能体系统
15天完整分工表
P1: 一、项目总目标
P2: 15天内完成一个可演示的多智能体系统原型：用户选择香港空气质量站点与时间段后，系统自动调用7个专业Agent，输出空气污染异常识别、气象扩散风险、交通源可能性溯源、区域分流/限行建议和自动治理报告。
P3: 系统定位：证据链式交通源可能性溯源 + 建议级区域治理方案。
P4: 功能边界：不做自动执法级限行；不承诺精确分车型排放贡献率；重点输出“可能性评分 + 证据链 + 建议方案”。
P5: 数据基础：香港EPD历史AQHI/多污染物数据、Open-Meteo气象数据、香港2018—2024交通统计数据，并补充道路网络与敏感POI。

P102: def coordinator_analyze(station, start_time, end_time):
    air_result = AirQualityAgent.run(station, start_time, end_time)
    meteo_result = MeteorologyAgent.run(station, start_time, end_time)
    traffic_result = TrafficAgent.run(station, start_time, end_time)
    spatial_result = SpatialAgent.run(station, start_time, end_time, meteo_result)
    source_result = SourceAgent.run(air_result, meteo_result, traffic_result, spatial_result)
    decision_result = DecisionAgent.run(source_result, traffic_result, spatial_result)
    report_result = ReportAgent.run(
        air_result, meteo_result, traffic_result,
        spatial_result, source_result, decision_result
    )
    return {
        "air_quality": air_result,
        "meteorology": meteo_result,
        "traffic": traffic_result,
        "spatial": spatial_result,
        "source": source_result,
        "decision": decision_result,
        "report": report_result
    }
